## Controls
| Key | Action |
|-----|--------|
| Left / Right or A / D | Move the paddle |
| Space | Launch the ball |
| Up / Down | Move through the menu |
| Enter | Select / return to menu |
| Esc | Save the game and return to menu |

## How to Run
1. Clone this repository.
2. Download SFML 3 (Visual C++, 64-bit).
3. Open the project in Visual Studio and select Debug, x64.
4. In project properties, set the C++ standard to C++17 or newer, add SFML's `include` and `lib` folders, and link `sfml-graphics-d.lib`, `sfml-window-d.lib` and `sfml-system-d.lib`.
5. Copy the DLLs from SFML's `bin` folder next to the built `.exe`.
6. Make sure `level.txt` is in the project folder, then build and run.

## Power-Ups
- **W**: wider paddle for 10 seconds
- **+**: one extra life
